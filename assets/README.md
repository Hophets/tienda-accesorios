# Recursos visuales

- `hero.png` y `collection.png`: imágenes de productos de ejemplo generadas con la herramienta de generación de imágenes de OpenAI para este proyecto. Son representaciones ilustrativas, no fotografías del inventario real de Modesta. La cuadrícula de catálogo se muestra por encuadres CSS sin peticiones externas.
- `favicon.svg`: monograma creado para esta página.
- `fonts/manrope.ttf`: Manrope, distribuida bajo SIL Open Font License 1.1. Fuente oficial: https://github.com/google/fonts/tree/main/ofl/manrope. Licencia incluida en `fonts/manrope-LICENSE.txt`.
- `fonts/cormorant-garamond.ttf`: Cormorant Garamond, distribuida bajo SIL Open Font License 1.1. Fuente oficial: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond. Licencia incluida en `fonts/cormorant-garamond-LICENSE.txt`.

Sustituye las representaciones del catálogo por fotografías y datos reales antes de usar la tienda comercialmente.
